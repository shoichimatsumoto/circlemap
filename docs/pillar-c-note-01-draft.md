Erg が買えない。2026年、エログ初心者はここから始める

---

「動画まとめサイトで稼ぎたい」

調べるうちに **Erg（エルグ）** という WordPress 向けの自動投稿プラグインを知った人、多いと思います。

記事を自動生成して、エロタレストへの掲載も最適化してくれる。Pro なら 2万円前後、Max なら 5万円前後。

……ところが **2026年7月時点で、公式サイト erog.dev が開けない** 状態です。DNS すら引けないこともあり、新規購入は現実的に無理そうです。

私もここで一度止まりました。

でも **「エログ × エロタレ」自体が終わったわけではない** ので、  
**エログ（動画まとめ）** を副業のひとつとして、まず **Blogterest から手動〜半自動** で試し、その過程を note に残していこうと思います。

この記事は **無料の第1弾** です。  
「先生」ではなく **これから試す人間のメモ** として書いています。

---

### エロタレストって何をしてるの？

一言でいうと **「エログ運営者のための集客ハブ」** です。

```
① 個人のまとめブログ（エログ）
      ↓ 記事を書く
② エロタレスト（movie.eroterest.net）
      ↓ 動画を一覧・検索
③ DMM / MGS などの動画サイト
      ↓ 購入・会員登録
   アフィリ報酬 → ブログ主
```

エロタレから直接大金が入るわけではなく、基本は **動画アフィリ** です。

個人ブログだけでは集客しにくいので、**エロタレに記事を載せてもらい、逆流入ももらう** という相互送客のゲームになっています。

---

### ランク制度（ここを知らないと始められない）

エロタレには **サイトランク（0〜6）** があります。

ざっくり言うと:

- **IN アクセス** … 自分のサイトからエロタレへ送ったアクセス
- **平均 PV** … エロタレ上でユーザーが何ページ見たか

この2つの掛け合わせが **直近3日間** で評価され、ランクが上下します。

IN : OUT = **1 : 20** くらいが普通、**1 : 10〜15** だとランクを上げやすい、という目安がよく語られます（参考: [hiro-pchk 氏の解説](https://hiro-pchk.com/) など）。

ランクが上がると:

- エロタレからの **逆流入が増える**
- **RSS クローラー** が記事を回収しに来る時間帯が安定する
- **1日に載せられる記事数** のインパクトが大きくなる

つまり **SEO だけでなく「エロタレのルールゲーム」** もセットで理解が必要です。

### Erg がやっていたこと（＝今自分で用意するもの）

| Erg が自動化 | 初心者が代替する方法 |
|-------------|---------------------|
| 記事タイトル・本文生成 | テンプレ + 手書き（後で Cursor 等） |
| 予約投稿 | Blogterest / WP の予約機能 |
| ランク別の投稿時間 | 公開情報の時刻表 + 手動予約 |
| 7日間の重複チェック | スプレッドシート |
| 1日24本投稿 | 最初は **1日5本** からで OK |

**完全自動は最初から狙わない。**  
Erg Max の「内部最適化」は再現しにくいですが、**公開されている運用ルールの 40〜50% は手動でも入れられます。**

---

### 2026年、初心者のルート3つ

| ルート | 初期費用 | 自動化 | 向いてる人 |
|--------|---------|--------|-----------|
| **Blogterest + エロタレ** | 低 | 半自動が上限 | まず試したい人（私はここ） |
| **WordPress + 手動/プラグイン** | 中 | 中〜高 | Erg 代替を探す人 |
| **Next.js 自前サイト** | 低〜中 | 高 | 開発 or Cursor に任せられる人 |

**私の選択: Blogterest から。**

理由:

1. プログラミングほぼ不要
2. エロタレ連携が最初から組み込みやすい
3. 1週間で「合う/合わない」がわかる
4. 合わなければドメインごと撤退もしやすい

### 注意（初心者がハマりやすいところ）

1. **同じ動画を7日以内に再投稿** → 遅延公開ペナルティ
2. **予約投稿を5〜10分空けて公開** → 次の RSS 収集に間に合わないことがある → **1〜2分以内にまとめる**
3. **違法アップロード系・問題のあるタグ** → アウト。DMM/MGS 協力ルートでもグレーは触らない
4. **「確実に稼げる」系の高額 note** → 実績のないうちは書かない（私も）
