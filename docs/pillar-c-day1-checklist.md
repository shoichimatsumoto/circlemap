## Part A: note（30分）

### A-1. アカウント作成

1. [note.com](https://note.com/) を開く
2. **ログイン** → Google / X / メール いずれか
3. **プロフィール設定**
   - 名前: 本名でなくて OK（例: 「エログ試行錯誤中」）
   - 自己紹介: 1行で OK（例: 「柱C エログを Blogterest から始めます。記録用 note」）
   - アイコン: 任意（ロゴ不要）

### A-2. 第1弾を公開

1. 右上 **投稿** → **テキスト**
2. `docs/pillar-c-note-01-draft.md` の **「本文（ここからコピー）」** を貼る
3. タイトル: **Erg が買えない。2026年、エログ初心者はここから始める**
4. 料金: **無料**
5. ハッシュタグ: `#エログ` `#エロタレスト` `#副業` `#Blogterest`
6. **公開**

### A-3. メモ

```
公開 URL: https://note.com/ero_log_memo/n/n33830aacf1f9 ✅
公開日: 2026-07-06 ✅
```

→ 第2弾・Blogterest 申請時に貼る

## Part B: Blogterest（20分）

**詳細手順:** [`pillar-c-blogterest-manual.md`](pillar-c-blogterest-manual.md)

### B-1. サイト作成

1. Blogterest のトップ（`blogterest.net`）→ **ブログ作成**
2. 入力例:

   | 項目 | 例 |
   |------|-----|
   | サイト名 | 任意（短く） |
   | ドメイン | `yourname.blogterest.net`（半角英数字・3文字以上） |
   | メール | 確認メールが届くアドレス |
   | パスワード | 4文字以上 |

3. 確認メール → ログイン

### B-2. サイト URL をメモ

```
ドメイン: erologmemo.com ✅（2026-07-07 お名前.com）

## Part D: 記事を今日5本（60〜90分）

審査は **30記事** が目安。**今日5本 → 1週間で30本** を狙う。

### 1記事の型（コピペ用）

```
【タイトル】SEO用キーワード入り（MM号 / 素人ナンパ 等）

【本文】
・2〜3行の説明
・「動画はこちら」→ エロタレ or DMM リンク

【カテゴリ・タグ】

### 注意

- **同じ動画を7日以内に再投稿しない**（スプレッドシートで URL を記録）
- 問題のあるカテゴリ・表現は使わない
