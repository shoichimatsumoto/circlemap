## 手順（15〜30分）

### Step 1: 管理画面にログイン

1. http://erologmemo.com または http://erologmemo.blogterest.net/
2. 画面の **ログイン** から管理画面へ
3. **新規記事**（または記事作成）を開く

---

### Step 2: 動画を1本選ぶ

**ネタの探し方（手動・安全ルート）:**

1. [動画エロタレスト](https://movie.eroterest.net/) でキーワード検索  
   例: `素人ナンパ` `MM号` など
2. 気になる動画を開く
3. **元動画サイトへのリンク先** をメモ（後で記事に貼る）
4. サムネ画像があれば保存（Blogterest の画像欄に使う）

**禁止:**

- 他サイトの記事をそのままコピペ
- 7日以内に同じ動画URLを再投稿
- 問題のあるカテゴリ・表現

---

### Step 3: タイトルを書く

**型（コピペしてキーワードだけ差し替え）:**

```
＜MM号＞〇〇な美巨乳ギャルのエロ動画ｗ【素人ナンパ】
```

または

```
【素人ナンパ】〇〇してしまった〇〇の動画まとめ
```

- **SEO用キーワード** を前半に入れる
- 他サイトのタイトルを **そのまま真似しない**（参考程度）

---

### Step 4: 画像を入れる（必須）

**毎回この順（1本目と同じ）:**

```
サムネ保存 → JPG に変換 → Blogterest にアップロード
```

Blogterest は **WebP 非対応**。エロタレのサムネは `.png` でも中身 WebP なので、**保存直後に必ず JPG 変換** する。

#### Mac で JPG 変換（どちらか）

**A. スクリプト（おすすめ）**

```bash
cd ~/Desktop/circlemap/circlemap/docs
./convert-erolog-thumb.sh ~/Downloads/保存したファイル名.png
```

→ `thumb-20260708-225500.jpg` が同じフォルダにできる → **これを** アップロード

**B. プレビュー**

1. 保存した画像を「プレビュー」で開く
2. ファイル → **JPEGで書き出す**
3. 拡張子 `.jpg` のファイルをアップロード

#### Blogterest に入れる

Blogterest には **2種類の画像** がある:

| 表示場所 | 意味 | 入れ方 |
|---------|------|--------|
| 左の小さい枠（NO IMAGE） | **一覧サムネ** | 記事フォーム **上部** の「サムネイル」等 **または** 本文 **先頭** の画像 |
| 本文の中 | 記事本文用 | 「画像」タブで挿入 |

```
① NO IMAGE の枠を全部削除
② JPG 変換（file コマンドで JPEG と確認）
③ 記事フォーム上部に「サムネイル」欄があれば → そこに .jpg
④ なければ「画像」タブ → 本文の **いちばん上**（文字より前）に .jpg を1枚
⑤ エディタ内プレビュー確認 → 更新
⑥ 1本目（page/1/）と表示を比較
```

> 他サイトの画像URL直貼りは NO IMAGE になる。**JPG をアップロード**のみ。

### 画像が入らないとき

| 原因 | 対処 |
|------|------|
| エロタレから保存できない | サムネを **右クリック → 新しいタブで画像を開く** → そこから保存。ダメなら **スクショ** して JPG で保存 |
| **WebP（.png でも中身 WebP）** | Mac「プレビュー」または `docs/erolog-thumb-01.jpg` のように **JPEG に変換** |
| iPhone の HEIC | Mac の「プレビュー」で **JPEG に書き出す** |
| ファイルが大きい | 横幅 **800px 前後**、**500KB 以下** に圧縮してからアップロード |
| 操作が足りない | **画像タブ** → アップロード → **挿入/確定ボタン** を押す（選んだだけでは入らない） |

**2つの入れ方（どちらかでOK）:**

```
A. 本文の「画像」タブ → ファイル選択 → 挿入
B. 文章タブのツールバー「画像アイコン」→ アップロード → 挿入
```

記事フォームの **上部** に「サムネイル」「一覧用画像」欄があれば、**そちらにも** 同じ画像を入れる。

**どうしても入らない場合:** 文字だけでも記事数にはカウントされる。30本申請後に画像を足してもOK。

**更新直後に NO IMAGE のまま:** Blogterest は **画像反映に数分〜十数分** かかることがある。JPG を入れてエディタ内プレビューが出ていれば、5〜10分待ってからページを再読み込み（スーパーリロード）する。

### 「NO IMAGE」と表示される

画像の **枠だけ登録** され、ファイル本体が Blogterest に載っていない状態。

```
① 記事を編集
② NO IMAGE の枠をすべて削除（× または 削除）
③ WebP/HEIC ではなく JPG を使う（docs/erolog-thumb-01.jpg 等）
④ 「画像」タブ → JPG を選択 → 挿入 → プレビューで表示確認
⑤ 更新
```

**やってはいけない:** エロタレの画像URLを本文に直貼り（外部リンクは NO IMAGE になる）

### Step 5: 本文を書く

**型:**

```
（2〜3行の説明。動画のあらすじ風。露骨すぎる表現は避ける）

動画はこちら
```

「動画はこちら」を選択 → **リンクボタン（鎖マーク）** で Step 2 の動画向きURLを貼る。`→` や生URLの行は書かない。

**リンク先（3箇所とも同じURL）:**

- サムネ画像のクリック先
- 本文の「動画はこちら」
- 記事下の画像（pagePiece）

**貼るURL:** Senzuri / VJAV / TokyoMotion 等の **対応動画サイトの直URL**（`movie.eroterest.net` は使わない）

---

### Step 6: カテゴリ・タグ

- カテゴリ: 1つ（例: `素人ナンパ`）
- タグ: **最大8個**（SEO用キーワードを入れる。5〜8個推奨）

**タグの入れ方（例・7本目）:**

```
宮島めい / 催眠 / アスリート / スポコス / 中出し / 陸上 / 教え子 / 潮吹き
```
