# 同期ツールの認証設定

Vercel の SYNC_SECRET と CRON_SECRET には、暗号学的に安全な乱数から生成した別々の値を設定してください。実値をコード、ドキュメント、Git に保存しないでください。

同期ツールは https://www.circlemap.jp/tools/sync を開き、Vercel に設定された SYNC_SECRET を入力して利用します。secret を含む URL の共有や保存は避けてください。

環境変数を変更したら再デプロイして反映してください。以前の固定値は認証に使用できません。ローカル実行や外部の同期ジョブでも、新しい値を安全な環境変数管理経由で設定してください。
