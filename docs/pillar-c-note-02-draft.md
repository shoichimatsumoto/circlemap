### Blogterest の印象

思っていたより **デザインはシンプル** でした。

でもエログ界隈は **記事量とエロタレ連携** が本体で、見た目は二の次、という理解に切り替えました。

無料・予約投稿・エロタレ連携が最初からあるのは助かります。

### 独自ドメイン設定（お名前.com）

Blogterest の指示どおり、DNS の **A レコード** を設定しました。

```
VALUE: 209.58.177.64
```

お名前.com で **DNSレコード設定** を有効にする際、**ドメインプロテクション（1,364円/税込）** がかかりました。想定外でしたが、DNS を自分で触れるようになったので、このコストは「インフラ代」として割り切っています。

反映は **数時間〜1日** ほどかかりました。

---

### 「保護されていない通信」について

`http://erologmemo.com` を開くと、ブラウザが **「保護されていない通信」** と表示します。

Blogterest は **https 非対応** なので、**http のまま運用する前提** です。サイトが壊れているわけではありません。
