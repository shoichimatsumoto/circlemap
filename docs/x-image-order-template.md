# CircleMap X 画像外注 — 発注テンプレ（画像だけ・500〜1,000円）

**範囲:** Canva 加工のみ（文案・投稿は依頼者）  
**単価目安:** 1本（作品1本＝加工画像5枚）**500〜1,000円**  
**納期目安:** 2〜3日  
**詳細手順:** [`x-image-outsourcing-manual.md`](./x-image-outsourcing-manual.md)

## 1. 募集文（クラウドワークス等・コピペ用）

```
【CircleMap】同人紹介用の画像加工（Canva・週1本）

■ 内容
指定の作品ページからサンプル画像を保存し、
Canvaで X投稿用に加工してください（1本あたり5枚）。

■ 納品物
・PNG 5枚（1080×1350・4:5）
・ファイル名: 作品ID-01.png 〜 05.png（01が1枚目）

■ 単価
1本 500〜1,000円（応相談）
※ まずはお試し1本からお願いします

■ 作業時間の目安
1本 30〜60分程度

■ 必須スキル
・Canvaが使えること
・指示どおりにトリミング・余白・透かしを入れられること

■ 注意（必ず守ること）
・R-18作品のサンプルを扱います（成人向け画像の加工です）
・局部特写・露骨すぎるコマは使わない／顔・構図側にトリミング
・画像に作品タイトル・ハッシュタグ・大きな宣伝文は入れない
・右下に小さく「circlemap.jp」のみ

■ こちらが渡すもの
・作品ページURL（CircleMap）
・必要なら参考画像のスクショ

■ 投稿・Xアカウント操作は不要です（画像納品のみ）
```

## 3. 納品チェック（あなた用・1分）

- [ ] 5枚（または4枚以上）届いている
- [ ] **01がソフト**（H本番・局部寄りでない）
- [ ] 1080×1350っぽい縦長
- [ ] 右下に `circlemap.jp`
- [ ] 作品タイトル文字入れなし
- [ ] 露骨すぎるコマが残っていない

NGなら差し戻し例:

```
ありがとうございます。差し替えお願いしたいです。
・01を、もっと日常・表情寄りのコマに変更
・○枚目は露骨なので別コマに差し替え or 顔側にトリミング
```

## 4. あなた側の作業（外注後・約5分）

1. 加工済み01〜05を X に添付  
2. スレッド投稿（文案は自分でコピペ）  
3. メディアはセンシティブ設定ONのまま

```
（2/5）
```

```

```

※ 作品タイトル（R18）はリンク先で確認
