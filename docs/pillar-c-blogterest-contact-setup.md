## 全体の流れ（15〜20分）

```
① サイト設定で問い合わせフォームを有効化
```

## Step 1: 問い合わせフォーム（サイト設定）

1. 管理画面ログイン → http://erologmemo.blogterest.net/kanri/page/
2. **「サイト設定」** タブ
3. **問い合わせ** / **お問い合わせフォーム** / **表示ブロック** の項目を探す
4. **問い合わせを有効** にして **保存**
5. トップページを開き、**問い合わせリンク or フォーム** が出るか確認

> 管理画面の **「問い合わせ」** タブは受信トレイ。フォーム自体は **サイト設定** で有効化する。

### 通知メール

サイト設定に **通知先メール** があれば、Blogterest 登録メールを設定。

## Step 2: 運営者情報（新規記事）

**記事** → **新規記事**

**公開** → URL をメモ（例: `page/8/`）

## Step 5: フッターにリンク追加（1つずつ）

### 準備：記事のURLをコピー

1. 管理画面 → **「記事」** タブ
2. **運営者情報** の **プレビュー** をクリック
3. ブラウザのアドレスバーのURLをコピー  
   例: `http://erologmemo.blogterest.net/page/8/`
4. 同様に **プライバシーポリシー** のURLもコピー  
   例: `http://erologmemo.blogterest.net/page/9/`

---

### 手順 1：サイト設定を開く

1. 管理画面上部の **「サイト設定」** タブをクリック

---

### 手順 2：フッター設定の場所を探す

画面を下にスクロールし、次のいずれかを探す:

- **フッターメニュー**
- **サイトメニュー**
- **表示ブロック** → フッター
- **カスタムリンク**

> 見つからない場合は **サイト設定** 画面のスクショを送ってください。

---

### 手順 3：1つ目「運営者情報」を追加

1. **「リンクを追加」** / **「メニュー追加」** / **「＋」** をクリック
2. 入力:

| 項目 | 入力値 |
|------|--------|
| 表示名（リンク文字） | `運営者情報` |
| URL | 手順「準備」でコピーした運営者情報のURL |

3. **追加** / **確定**

---

### 手順 4：2つ目「プライバシーポリシー」を追加

1. もう一度 **リンクを追加**
2. 入力:

| 項目 | 入力値 |
|------|--------|
| 表示名 | `プライバシーポリシー` |
| URL | プライバシーポリシーのURL |

3. **追加** / **確定**

---

### 手順 5：問い合わせについて

トップ下部に **問い合わせフォーム**（名前・メール・内容）が出ていれば **追加不要**。

出ていなければ、サイト設定の **問い合わせを有効** をONにして保存。

---

### 手順 6：保存して確認

1. 画面下の **「保存」** / **「設定する」** をクリック
2. http://erologmemo.com を **再読み込み**（スーパーリロード）
3. ページ最下部に次があるか確認:

```
運営者情報 | プライバシーポリシー | 問い合わせフォーム
```

4. 各リンクをクリックしてページが開くか確認

---

### うまくいかないとき

| 症状 | 対処 |
|------|------|
| フッター項目が見つからない | サイト設定のスクショを送る |
| リンクを押しても404 | URLを `http://erologmemo.com/page/X/` で再入力 |
| 保存しても出ない | 5分待って再読み込み |
