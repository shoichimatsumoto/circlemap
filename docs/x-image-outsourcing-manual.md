# CircleMap X 画像加工マニュアル（外注・Canva）

x-draft ページの ★ サムネを、X 投稿用に加工する手順です。

---

## 1. いつ加工するか

| 投稿タイプ | 画像 | 理由 |
|-----------|------|------|
| 人気TOP3 | **3枚コラージュ** | まとめ感・クリック率 |
| 週次まとめ | **3枚コラージュ** | 同上 |
| 注目サークル | ★1枚そのまま or 軽クロップ | サークル1本に集中 |
| 豆知識・バズ | なし or サイト画像 | テキスト中心 |
| フック・拡散向け | **3枚コラージュ必須** | 目立たせる |

**コラージュ不要** … ★ サムネをそのまま保存 → X に添付（露骨すぎる場合は下記「画像なし」）

---

## 2. 禁止・注意（必読）

- 本文に **R-18 作品タイトル・URL を入れない**（x-draft の ① をそのまま使う）
- サムネに **モザイクのかかっていない局部特写** があれば使わない → **画像なし投稿**
- 画像に **作品タイトル（R-18）を文字入れしない**
- 右下の `circlemap.jp` 以外に **大きな宣伝文** を入れない
- **# ハッシュタグ** を画像に入れない

---

## 3. Canva 手順（3枚横並び・4:5）

### 準備

1. [Canva](https://www.canva.com/) を開く（無料アカウントで OK）
2. **カスタムサイズ** → **1080 × 1350 px**（4:5・X 向き）→ 作成
3. x-draft の **★ サムネ** と、必要なら 2・3 枚目を PC に保存（長押し / 右クリック → 保存）

### 背景

4. 左メニュー **「デザイン」** → 背景色 **#0f0f12**（黒に近いグレー）  
   ※ なければ **#1a1a22** でも可

### 3枚配置

5. **「アップロード」** で保存したサムネを 3 枚アップ
6. 各画像を配置（目安）:

   | 位置 | X 座標目安 | 幅 × 高さ目安 |
   |------|-----------|---------------|
   | 左 | 40px | 300 × 400 px |
   | 中央 | 390px | 300 × 400 px |
   | 右 | 740px | 300 × 400 px |

7. 3 枚の **上端を揃える**（Canva のガイドで中央揃え）
8. 画像は **角丸 8px**（任意・統一感）

### 露骨な部分がある場合

- その画像は **使わない** → 別のサムネに差し替え
- または **拡大して問題ない部分だけ** トリミング（顔・表紙・構図のみ）

### 右下テキスト

9. **「テキスト」** → 追加 → `circlemap.jp`
10. フォント: **Noto Sans JP** または **Inter**（太字）
11. サイズ: **24〜28px**
12. 色: **#a78bfa**（紫）または **#ffffff**
13. 位置: **右下**（右端・下端から 24px 余白）

### 書き出し

14. **共有** → **ダウンロード** → 形式 **PNG** → ダウンロード
15. ファイル名例: `circlemap-x-20260705-popular.png`

---

## 4. ★1枚だけ使う場合（軽加工）

1. Canva **1080 × 1350 px** を新規作成
2. 背景 `#0f0f12`
3. ★ サムネを中央に配置（幅 720px 前後、比率維持）
4. 右下に `circlemap.jp`（上と同じ）
5. PNG で書き出し

---

## 5. 投稿の流れ（画像〜X）

x-draft ページの順番どおり:

```
A. 加工済み PNG（または ★ そのまま）を X に添付
B. ③ @メンション — サークル公式が X にあれば @ を ① に足す
C. ① 本文を投稿（コピーボタン）
D. 自分の投稿に ② リプライ用リンクを返信（コピーボタン）
```

---

## 6. 完了報告フォーマット

投稿後、依頼者に以下を送る:

```
【CircleMap X 投稿完了】
日付: 2026/07/05
タイプ: 人気TOP3
投稿URL: https://x.com/circlemap_jp/status/xxxxxxxx
画像: 3枚コラージュ / ★そのまま / 画像なし
@メンション: あり（@xxxxx）/ なし
```

---

## 7. トラブル時

| 状況 | 対応 |
|------|------|
| 3 枚とも露骨 | **画像なし**で ①② だけ投稿 |
| Canva が英語 | ブラウザ翻訳 or サイズだけ 1080×1350 で OK |
| サムネが保存できない | x-draft の画像を新しいタブで開いて保存 |
| センシティブ警告 | 画像を削除して再投稿 or アカウント設定でメディア警告を確認 |
