# 作品ページ「同じ系統の作品」（同タグ・別サークル）表示ルール案

目的: 閲覧者の趣味（タグ）に沿った一覧で **回遊率を上げる**。  
サークル内だけだと止まってしまう回遊を、**別サークルの同系統**へ伸ばす。

実装は今月末の様子見明け以降を想定。このドキュメントはルールの合意用。

---

## 1. 既存との役割分担

| ブロック | 中身 | 役割 |
|----------|------|------|
| **A. 同じサークルの他作品**（既存） | 同一 `circle_id` | サークル軸・差別化の本丸 |
| **B. 同じ系統の作品**（新規・本ドキュメント） | 同タグ・**別サークル** | 趣味回遊・掘り出し |

**両方出す。** B で A を置き換えない。

表示順（作品ページ）:

```
[購入ボタン]
[作品情報]
[A. ○○の他作品]          ← 既存
[B. 同じ系統の作品（#タグ）] ← 新規
```

B を購入ボタン直下に置く案もあるが、初版は **A の下** が安全（サークル寄りを崩さない）。

---

## 2. どのタグで集めるか

作品の `tags` は現状最大おおよそ6件（DMM genre 由来）。

### ルール

1. **候補タグ** = 当該作品の `tags`（空なら B ブロックごと非表示）
2. **除外タグ（汎用すぎる）** — マッチに使わない  
   例（初版リスト・後で調整可）:
   - `男性向け` / `成人向け` / `専売` / `同人` / `マンガ` / `CG` / `ボイス` / `ゲーム`
   - `イラスト・CG集` など媒体そのものを示すもの
3. **優先タグの選び方**
   - 除外後のタグから **最大2つ** を「系統タグ」にする
   - 優先順（本番頻度 2026-07-20 反映）:
     1. **全体付与率が低い方を優先**（例: `#人妻` を `#中出し` より先に）
     2. 付与率の目安帯: **だいたい 2%〜25%** を最優先。  
        50%超（`中出し` `巨乳` など）は **除外はしない** が、他に候補があるときは選ばない
     3. 配列の先頭寄り（DMM側の並び）は同率のタイブレーク
4. **表示見出し**  
   - 系統タグが1つ: `同じ系統の作品（#人妻）`  
   - 2つ: `同じ系統の作品（#人妻・#NTR）`  
   - 「もっと見る」リンク先（当面）: `/search?q=（主タグ）`  
   - 将来: `/tag/人妻` に差し替え

---

## 3. 取得・フィルタ

対象作品は次をすべて満たすもの。

| 条件 | 内容 |
|------|------|
| タグ一致 | 系統タグのうち **1つ以上** を含む |
| 別サークル | `circle_id` ≠ 現作品 |
| 自分除外 | `id` ≠ 現作品 |
| サムネあり | `thumbnail_url` がある（カードが空にならない） |

### 並び（初版）

1. `popularity_rank` があるもの優先（昇順＝人気上位）
2. なければ `date` 降順（新しい順）
3. 同一サークルから **最大1件**（掘り出しを広げ、1サークルに固まらない）

### 件数

| 項目 | 値 |
|------|-----|
| 表示 | **6件**（デスクトップ／スマホとも） |
| 取得試行 | 最大 **24件** 拾ってから上記フィルタで絞る |
| 不足 | **3件未満なら B ブロックごと非表示**（寂しい枠を出さない） |

## 4. UI（初版）

- 既存の `yt-grid` + `WorkCard` を流用（A と同じ見た目）
- セクション見出し + `link-more`: `「#人妻」をもっと見る →` → `/search?q=人妻`
- 媒体バッジはそのまま（漫画/CG/音声が混在してOK＝横断が売り）

コピー案:

```
同じ系統の作品
#人妻 などでつながる、別サークルの作品です。
```

短くするなら見出しだけでも可。

---

## 5. やらないこと（初版）

- 自動スライド・無限スクロール
- 全タグ横断の巨大クエリ（性能・ノイズ）
- タグ専用ページ `/tag/`（①は別タスク。リンク先だけ将来差し替え）
- 「おすすめアルゴリズム」の複雑化（人気順＋日付で十分）

## 10. 除外／採用タグ（合意内容）

方針: **全員に付くラベルは除外。趣味の手がかりになるタグだけマッチに使う。**  
（画面上の `#タグ` 表示自体は除外タグでも残してよい）

### 除外する（マッチに使わない）

**A. 属性・レーティング**
- 男性向け（約23%） / 女性向け / 成人向け（約14%） / 専売（約4%） / 同人

**B. 媒体・形式そのもの**
- マンガ / 漫画 / CG / ボイス / 音声 / ゲーム
- イラスト・CG集（約8%）
- 動画・アニメーション（名称ゆれ含む・約7%）
- 3DCG（約2%）
- 音声付き（約5%）

**C. 本番頻度で追加したメタ情報（趣味ではない）**
- デモ・体験版あり（約5%）

### 除外しない（回遊・マッチに使う）※頻度が高くても除外しない

本番TOP付近の例（付与率はおおよそ）:

| タグ例 | 付与率目安 | 扱い |
|--------|------------|------|
| 中出し / 巨乳 / フェラ | 38〜56% | **採用可**だが、系統タグ選出では **後回し** |
| 制服 / おっぱい / 辱め / 寝取り・NTR / 学園もの | 16〜23% | 採用・選出候補 |
| ぶっかけ / パイズリ / 野外・露出 / 人妻・主婦 | 10〜16% | 採用・選出候補 |
| 熟女 / ギャル / 水着 / ラブラブ・あまあま / ファンタジー | 4〜7% | **選出向き** |
| コスプレ / メイド / 幼なじみ / ハーレム など | 2〜4% | **選出向き** |

強めタグは「表示してよいか」と「マッチに使うか」は別。**マッチには使ってよい**（初版）。  
ただし **50%前後の超高頻度タグだけを系統タグにすると関連がぼやける** ので、選出時は低頻度タグを優先する（セクション2）。
