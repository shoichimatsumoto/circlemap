### 30本までの運用（変わらなかったこと）

やり方はシンプルなままです。

```
動画を1本選ぶ
→ タイトル・説明文・本文・タグを書く
→ サムネをJPGに変換してアップロード
→ 公開
```

**1日3本ペース** で、約1週間で30本に到達しました。

気にしていたこと：

- **同じ動画は7日以内に再投稿しない**
- 説明文は毎回入れる（RSSのdescriptionにも載る）
- サムネはWebPのまま入れない（BlogterestはJPG推奨）

特別な自動化は使っていません。Blogterestは手動投稿のみです。

### エロタレ申請（1回目）

30本・ブログパーツ・問い合わせが揃ったので、エロタレストにサイト登録を申請しました。

申請時に入れた主な情報：

- サイトURL … `http://erologmemo.com`
- RSS … `http://erologmemo.com/feed/`
- ブログパーツ … 全ページ共通のヘッダー直下

### 1回目：不承認（RSSの件数）

数日後、こんな内容のメールが届きました。

> 収集可能なコンテンツが確認できませんでしたので、今回は掲載を見合わせていただきます。

最初は「30本あるのに？」と思いました。

Blogterestのサイト設定にこう書いてありました。

> エロタレは手動反映になり、RSSは読みにきません

一方、エロタレの審査では **RSSを確認する** ようです。

実際に `http://erologmemo.com/feed/` を見ると：

| 項目 | 申請時 | 問題 |
|------|--------|------|
| RSS記事数 | **10件** だけ | 30本あるのに10件しか出ていなかった |
| サムネ・説明文 | 10件分のみ | 審査側から見ると薄く見えた可能性 |
| サイト説明文 | 空 | meta情報が未設定だった |

**修正したこと：**

- RSS掲載件数を **10 → 30** に変更
- サイト説明文を1〜2行追加

保存後、feedを開いて **30件・サムネ・説明文** が出ていることを確認して再申請。

---

### 2回目：不承認（動画リンクの件）

また不承認。

今度は記事内のリンク先が問題でした。エロタレの **動画ページURL** を貼っていたのですが、**対応動画サイトへの直URL** が必要だったようです。

**修正したこと：**

記事内のリンク先を **3箇所とも** 動画向きURLに変更：

- サムネクリック時のリンク
- 本文の「動画はこちら」
- 下の画像リンク

使ったサイト例：Senzuri / VJAV / TokyoMotion / HDZog など（動画ごとに元サイトを確認）。

エロタレの動画ページURLは **エログ記事には貼らない** ようにしました。

---

### 3回目：不承認（再修正して再申請）

2回目の修正を全記事に反映し、再度申請。

明確な新しい理由のメールは来ませんでしたが、まだ通らず。引き続き記事を増やしながら待ちました。

---

### 4回目：不承認 → 対策 → 通過

4回目も一度落ちました。今回の指摘はだいたい次の2点でした。

1. **連動広告パーツ** が記事に入っていない
2. **タイトルの転用** が疑われる（他サイトと同じタイトルが多い）

**修正したこと：**

**① MGS連動広告パーツを全記事に設置**

Blogterestの「htmlソース / entryParts」欄に、MGSの連動広告パーツを入れました。  
あらすじ → パーツ → 「動画はこちら」の順で配置。

**② 直近10本のタイトルを言い換え**

エロタレのタイトルをそのまま使わず、自分の文案に変更。

この状態で再申請したところ、**4回目で通過** しました。

---

### 審査通過メールが来た

2026/07/17頃、こんなメールが届きました。

> サイトの登録が完了し、記事が収集できる状態になりました

登録ページ：エロタレ上でサイトID **s/20180** として表示

Blogterestの記事管理画面にも **「エロタレ反映」ボタン** が増えていました。

ポイント：

- RSSによる **自動収集はしない**
- **好きな時間に** 反映ボタンを押して記事を送る
- 1日 **30件まで**（6:00にリセット）
- 管理画面ログイン情報は **反映翌日10時過ぎ** の別メール

長かった。4回落ちて、ようやくここまで来ました。

---

### 反映しようとしたら…ドメイン不一致

通過直後、「エロタレ反映」ボタンを押したら **反映不可** になりました。

> ドメインが一致しません。独自ドメインに移行した場合は動画エロタレストにドメイン変更依頼を送ってください。

状況を整理すると：

| 項目 | 内容 |
|------|------|
| 申請・独自ドメイン設定 | `http://erologmemo.com` |
| 管理画面の記事URL | Blogterest サブドメイン側（独自ドメインと不一致） |

Blogterestのサイト設定にも、こう書いてありました。

> エロタレ登録済みの場合はドメインを変えた旨連絡してください。

エロタレに **ドメイン変更依頼メール** を送り、返信待ちです。  
審査は通っているので、あとはドメインのすり合わせだけ、という認識です。

### 初心者向けメモ：RSSは開いて確認する

エロタレ申請前に、自分で一度ここを開いてください。

```
http://あなたのドメイン/feed/
```

チェック項目：

- 記事が何件出ているか（30本あるなら30件出ているか）
- サムネ画像があるか
- 説明文が「動画を見る」などの誘導文だけになっていないか

Blogterestなら **RSS掲載件数** の設定を見逃しやすいです。
