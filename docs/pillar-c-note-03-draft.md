### 1回目：不承認（RSSの件数）

数日後、こんな内容のメールが届きました。

> 収集可能なコンテンツが確認できませんでしたので、今回は掲載を見合わせていただきます。

最初は「30本あるのに？」と思いました。

Blogterestのサイト設定にこう書いてありました。

> エロタレは手動反映になり、RSSは読みにきません

一方、エロタレの審査では **RSSを確認する** ようです。

実際に `http://erologmemo.com/feed/` を見ると：

| 項目 | 申請時 | 問題 |
|------|--------|------|
| RSS記事数 | **10件** だけ | 30本あるのに10件しか出ていなかった |
| サムネ・説明文 | 10件分のみ | 審査側から見ると薄く見えた可能性 |
| サイト説明文 | 空 | meta情報が未設定だった |

**修正したこと：**

- RSS掲載件数を **10 → 30** に変更
- サイト説明文を1〜2行追加

保存後、feedを開いて **30件・サムネ・説明文** が出ていることを確認して再申請。

### エロタレ反映で実際に出た警告（2026/07/19）

Blogterestの **「動画重複チェック」** と **「エロタレ反映」** を使い始めて、連続反映は難しい、と分かりました。

| 警告 | 意味 | 対処 |
|------|------|------|
| **同一動画の記事とタイトルが被っていた** | 同じ動画でタイトルが重複 | タイトルを言い換えて再反映 |
| **投稿日時が近すぎる（30分以上空けて）** | 反映間隔が短い | **30分以上空けて** 次を反映 |

ポイント：

- **連続でガンガン反映はできない**（30分間隔のルールあり）
- 予約投稿以外は **投稿日時が「今」に読み替えられる** ので注意
- 1日 **30件まで**（6:00リセット）は変わらず
- 新規記事は **公開前に動画重複チェック** → OKなら公開 → 反映

いまの運用：

```
反映可の記事だけ選ぶ
→ 1本反映
→ 30分空ける
→ 次を反映（1日30本まで）
```

本登録メール（管理画面ログイン情報）は **反映した翌日10時過ぎ** に届く予定です。

### 管理画面Q&Aで確認した公式ルール（2026/07/20）

本登録後、[ブログ管理者様管理ページ](https://movie.eroterest.net/site_admin/qa/) のFAQを読んだメモ。  
Blogterestは **RSS自動収集ではなく「エロタレ反映」ボタン** だが、**収集されない条件・表示遅延の考え方は同じ** と理解した。

#### 収集（反映）されない主な条件

- 記事に **動画へのリンクか埋め込みプレーヤー** がない
- **過去に同じ動画** を掲載済み（自サイト）
- **同じ動画＋他サイトとタイトル被り**
- 動画削除済み（FC2等のみ存在チェック）
- **アフィリエイトタグ付き** の動画埋め込み・リンク
- **特定キーワード**（肖像権クレーム等）
- **特定女優名** … 管理画面に長い禁止リストあり。**伏せ字・誤字で誤収集させようとするとサイト削除** と明記

#### 「表示遅延」と実際の挙動（体感と一致）

表示遅延中は **記事一覧に出ない**。期間が終わると通常表示。

遅延対象：

1. **同一動画** … 他記事投稿後 **一定期間（数日）以内** に投稿された記事
2. **見つけやすさランクが2未満** のサイトの記事

Blogterestの「07/XX以降なら回避可能」は **①の時間待ち** の説明として読める。  
**日時を覚えて待つより、反映可能なら反映して遅延を割り切る** 運用にした（自動化時もこの方針がシンプル）。

#### 掲載順位（点数化）

- サイトランク（直近3日のIN）
- 見つけやすさランク
- IN/OUT比率
- 送ったページビュー数

人気キーワード・女優名に合わせた **動画選定と独自タイトル** がINに効く、とFAQにもある。

#### 重複チェックの正体

**動画URL** で同じ動画とみなす。サムネ差し替えでは **重複遅延は変わらない**（転用対策・見た目用）。

#### その他メモ

- 記事収集サーバーIP: `153.122.98.4` / `153.122.110.85`（自サイトでIP制限している場合は除外）
- **ボット・スクレイピング禁止**（API自動化する場合も公式仕様を確認）
- 掲載停止は詐欺リンク・丸パク・無修正・局部サムネ等（再開不可のものあり）

### 管理画面：サイトランク・見つけやすさ（2026/07/20）

本登録後、管理画面で自分のサイト数値を確認した記録（[site_admin](https://movie.eroterest.net/site_admin/info/)）。

#### 当時の数値（エログメモ）

| 項目 | 値 | 意味 |
|------|-----|------|
| **サイトランク** | **1** | 直近3日間、エロタレへ送ったPVが少ない（新規サイトで普通） |
| **見つけやすさ PC** | **4** | 最高クラス。「優良」アイコン対象 |
| **見つけやすさ SP** | **3** | 良好 |

#### サイトランク1の制約（公式表より）

- RSS収集 **1日8回**（ランク6は48回）
- 一覧表示 **投稿日時+8分**
- **過去記事順位調整** × / **ブログパーツへの記事掲載** ×

→ Blogterestは **手動「エロタレ反映」** なのでRSS回数は直接は関係ないが、**一覧での見え方・INの少なさ** には効く。

#### 見つけやすさで見られるポイント（FAQ）

動画までスクロールが長い、騙しリンク、広告と動画リンクが詰まっている、等で **降格**。  
当サイトは **PC4/SP3** なので、**「見つけやすさ2未満で表示遅延」** のFAQ条件には **当てはまらない**（遅延は **動画重複** 側が主因）。

#### 掲載順位の基準値（当時）

```
サイトランク1     +8分
見つけやすさPC4  +40分
見つけやすさSP3  +30分
```

プラスが大きいほど一覧で上位寄り。IN/OUT比率が悪い等の **マイナス調整** は当時「いいえ」。

#### 過去記事の上位表示

「見つけやすさ4でOUTが少ない」→ **はい**（新着がないとき収集済み記事を上げる対象）。

#### 初心者向け解釈

```
見つけやすさ … デザイン・導線（当サイトは高め → 維持）
サイトランク … 直近3日のIN/PV（低い → 更新・流入を続けると上がる）
```

デザイン変更したら **エロタレに連絡** すると再審査猶予1週間あり（FAQ）。
