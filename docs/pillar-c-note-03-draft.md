### 30本までの運用（変わらなかったこと）

やり方はシンプルなままです。

```
動画を1本選ぶ
→ タイトル・説明文・本文・タグを書く
→ サムネをJPGに変換してアップロード
→ 公開
```

**1日3本ペース** で、約1週間で30本に到達しました。

気にしていたこと：

- **同じ動画は7日以内に再投稿しない**
- 説明文は毎回入れる（RSSのdescriptionにも載る）
- サムネはWebPのまま入れない（BlogterestはJPG推奨）

特別な自動化は使っていません。Blogterestは手動投稿のみです。

### エロタレ申請（1回目）

30本・ブログパーツ・問い合わせが揃ったので、エロタレストにサイト登録を申請しました。

申請時に入れた主な情報：

- サイトURL … `http://erologmemo.com`
- RSS … `http://erologmemo.com/feed/`
- ブログパーツ … 全ページ共通のヘッダー直下

---

### 不承認メールが来た

数日後、こんな内容のメールが届きました。

> 収集可能なコンテンツが確認できませんでしたので、今回は掲載を見合わせていただきます。

最初は「30本あるのに？」と思いました。

でも調べると、**RSSの中身** がポイントでした。

---

### 原因として考えたこと

Blogterestのサイト設定にこう書いてありました。

> エロタレは手動反映になり、RSSは読みにきません

一方、エロタレの審査では **RSSを確認する** ようです。

実際に `http://erologmemo.com/feed/` を見ると：

| 項目 | 申請時 | 問題 |
|------|--------|------|
| RSS記事数 | **10件** だけ | 30本あるのに10件しか出ていなかった |
| サムネ・説明文 | 10件分のみ | 審査側から見ると薄く見えた可能性 |
| サイト説明文 | 空 | meta情報が未設定だった |

記事ページ自体には「動画はこちら」リンクやサムネリンクはあるのに、**RSSに載る件数が少なかった** のがいちばん怪しいと判断しました。

---

### 修正したこと（2点だけ）

**① RSS掲載件数を10 → 30に変更**

Blogterest管理画面 → サイト設定 → 基本設定

保存後、`http://erologmemo.com/feed/` を開いて確認。

- 記事 **30件**
- 各itemに **サムネ画像**
- **説明文**（純粋な解説文のみ）

が出ていることを確認しました。

**② サイト説明文を追加**

空欄だったので、1〜2行の説明を入れました。

---

### 再申請（2回目）

修正後、同じフォームから再申請しました。

RSS URLは変えず、**`http://erologmemo.com/feed/`** のままです。  
（`/feed/all/` は30件あるもののサムネなしだったので使いませんでした）

備考欄には、前回不承認後にRSS件数とサイト説明を修正した旨を短く記載しました。

いまは **審査待ち（2〜3週間）** です。

---

### 審査待ちの間にやること

```
□ 1日3本ペースで記事を増やし続ける
□ 同じ動画の7日重複を避ける
□ 審査結果メールを待つ
```

審査中に更新が止まると不利、とよく言われるので、**投稿は続けます**。

---

### DMMアフィリについて（正直な記録）

並行してDMMアフィリも申請しましたが、**2回とも不承認** でした。

いまはエロタレ優先で、記事リンクはエロタレURLのまま運用しています。DMMはエロタレが落ち着いてから再チャレンジ予定です。

---

### 初心者向けメモ：RSSは開いて確認する

エロタレ申請前に、自分で一度ここを開いてください。

```
http://あなたのドメイン/feed/
```

チェック項目：

- 記事が何件出ているか（30本あるなら30件出ているか）
- サムネ画像があるか
- 説明文が「動画を見る」などの誘導文だけになっていないか

Blogterestなら **RSS掲載件数** の設定を見逃しやすいです。
